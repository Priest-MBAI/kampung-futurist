# Kampung Futurist: Explainer Series (2 × ~30s, 16:9)

Shared across both episodes:
- **Host:** Marcus Goh (Flow character, Algieba voice), with the same styling as the sizzle reel.
- **Theme song:** one original Flow Music track (upbeat lo-fi / light Singapore street vibe), ducked under the dialogue.
- **Graphics:** made in Remotion (OpenMontage). Kinetic keyword pops, plus faithful but stylised recreations of the Claude Code UI and the workflow. They are never passed off as real screenshots.
- **Live-action rule:** laptop screens stay angled away or out of focus. AI-generated screen text is a giveaway, so real UI only appears in the graphic inserts.
- **Each clip:** Omni 1.1 Flash, 16:9, with the @Marcus Goh character reference (plus @Me for Alan's scenes). Every spoken line is 20 words or fewer so it fits inside a clip.
